# Synthetic example

Run the app and choose **Open example**. `demo()` in `src/image.ts` creates a 1000 × 600 canvas with deterministic pseudo-random background noise and eight hand-specified lane patterns. It is generated code, not a laboratory photograph or a reconstruction of any research experiment.

The example contains a ladder, illustrative uncut/unknown lanes, and a PCR control. Existing demo annotations are pre-populated to explain the interface; they are not evidence of automatic lane detection. Re-run **Suggest bands** on a selected lane to exercise peak detection.

The PCR control can produce an approximate 1,000 bp estimate after the ladder mapping and sample observations are reviewed. This illustrative result does not establish detector or sizing accuracy.

Public screenshots live in `docs/assets/screenshots/` so GitHub Pages can serve them directly. No real gel images, saved project JSON, or analysis exports belong in this folder. Use local images outside the repository for private work.
