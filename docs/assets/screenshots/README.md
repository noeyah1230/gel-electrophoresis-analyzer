# Screenshot provenance

- `synthetic-workspace.png`: actual browser-preview interface showing the generated example, reviewed annotations in an uncut lane, and its brightness profile.
- `synthetic-calibration.png`: the same synthetic example with the ladder calibration panel open and the illustrative marker assignments reviewed.

Both are captured in a fresh automated browser context by `scripts/smoke.mjs`. They contain only pixels generated by `demo()` in `src/image.ts`, generic sample labels, and a synthetic demonstration note. No real image, patient/collaborator information, institutional material, or existing browser project is used. Browser chrome and filesystem paths are not included.

To regenerate, run `npm run dev` in one terminal and, in another:

```sh
# Requires Chrome installed locally. Alternatively install Playwright Chromium
# and omit BROWSER_CHANNEL=chrome.
BROWSER_CHANNEL=chrome node scripts/smoke.mjs --screenshots
```

The script exercises the app, captures two 1440 × 1050 viewport screenshots, and keeps test exports in ignored `.local/qa/`. Inspect replacement screenshots before publishing. Do not use a screenshot from a real research session.
